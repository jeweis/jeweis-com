# 几未同学的小工作台

一个无需构建、无需安装依赖的互动个人主页。使用原生 HTML、CSS 和 JavaScript，插画由 CSS 绘制，无外部字体或图片请求。

## 打开

直接用浏览器打开 `index.html`，或者在当前目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8765 。

## 可以做什么

- 点电脑：查看 mcpcat，并玩一个连接三个工具插头的小互动。
- 点随身听：查看《你爱的样子》，前往网易云歌曲页收听，或阅读歌曲百科。
- 点猫：听它说话，多点几次会挪位置。
- 点台灯：开关灯光。
- 点右上角月亮：切换白天与深夜。
- 点咖啡、便签：发现短句和给访客的信。

音乐弹窗已嵌入网易云外链播放器（歌曲 ID：474447967），手动点击播放，关闭弹窗会卸载播放器以停止播放。仅在打开音乐弹窗时加载网易云内容。实际播放取决于网易云的外链可用性；保留歌曲页入口 https://music.163.com/#/song?id=474447967 作为备用。

## 文件

- `index.html`：页面内容和工作台结构。
- `style.css`：插画、昼夜主题、桌面与手机布局，以及减少动态效果的适配。
- `app.js`：弹窗、工具连接小游戏、昼夜切换、猫和其他物品的互动。

## 部署

已配置 GitHub Actions 自动部署到 GitHub Pages。推送到 `main` 分支会发布网页，也可以在 Actions 页面手动运行部署。

- 仓库：https://github.com/jeweis/jeweis-com
- 网站：https://jeweis.github.io/jeweis-com/
- 仓库的 Settings → Pages → Source 应设置为 GitHub Actions。

工作流仅上传首页、样式和交互脚本。无后端和环境变量。
