# 几未同学的小工作台

把一些想法写成代码，把另一些写成歌。

**[来小房间坐坐 →](https://jeweis.com/)**

这里有一个慢慢打磨的项目、一首歌，以及一只叫迪西的猫。桌上的东西都可以碰。

- 点电脑，看看 [mcpcat](https://github.com/jeweis/mcpcat)，把三个工具插头连起来。
- 点随身听，听一首《你爱的样子》。
- 摸摸迪西：叫醒、伸懒腰、背过身，再慢慢睡回去。它还有一个在微信上班的小秘密。
- 开关台灯、切换昼夜，房间会记住你的偏好。

也可以直接去 **[迪西的微信营业部](https://jeweis.com/#dixi)**，看看《迪西有话说》和《迪西有点皮》两套表情包。

## 本地运行

无需安装依赖或构建，直接打开 `index.html`，或运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:8765 。

## 技术与部署

原生 HTML、CSS、JavaScript 和 SVG，适配电脑、手机和减少动态效果的设置。

网站托管在 GitHub Pages，推送到 `main` 后自动部署到 https://jeweis.com/ 。

开发和维护约定见 [AGENTS.md](AGENTS.md)。
