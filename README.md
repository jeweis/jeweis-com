# 几未同学的小工作台

一个无需构建、无需安装依赖的互动个人主页。原生 HTML、CSS、JavaScript 和内联 SVG，主页面无外部图片或字体请求。

## 本地打开

直接打开 `index.html`，或在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 http://127.0.0.1:8765 。

## 房间里的东西

- **SVG 小猫**：平时睡觉，桌面鼠标靠近会睁眼并轻微转头。点击叫醒，短时间再点伸懒腰，继续打扰就背过身；停止互动后自然恢复睡眠。手机通过点击触发。偶尔自主换姿势。
- **电脑**：展开 mcpcat 项目面板，连接三个插头，观察线路和集线器灯光；可前往 GitHub 查看项目。
- **随身听**：展开《你爱的样子》的音乐卡片，只在打开时加载网易云 iframe。手动播放，关闭面板时移除 iframe，停止后台播放。可用性取决于网易云，保留歌曲页备用链接。
- **台灯、昼夜**：开关实际场景灯光和环境颜色，偏好保存在本机浏览器；存储被禁用时仍能操作。
- **便签、咖啡**：给访客的一封短信和偶尔的小回应。

电脑详情在桌面呈显示器风格，音乐卡片在右侧展开；手机使用底部面板，控件保持可用尺寸。原生 dialog 支持 Escape、关闭按钮和遮罩关闭，并返回原入口焦点。开启系统“减少动态效果”后关闭动画、指针跟随和自动闲置动作。没有账号、访客追踪或后台服务。

## 验证

```sh
node --check app.js
node --test tests/room.test.cjs
```

测试使用受控时钟和轻量 DOM 替身，覆盖猫的状态恢复、连续点击、页面隐藏、音乐 iframe 卸载、焦点返回、插头状态和存储异常。它们不代替浏览器布局、辅助技术和音频试听检查。

## 部署

- 仓库：https://github.com/jeweis/jeweis-com
- 正式网站：https://jeweis.com/
- `www.jeweis.com` 跳转到根域名，HTTP 自动转 HTTPS。
- GitHub Pages Source：GitHub Actions。推送 `main` 自动发布，也可手动运行工作流。

部署仅上传 `index.html`、`style.css`、`app.js`、`CNAME` 和网站根目录的 `*.txt` 验证文件。微信验证文件需保留。测试、文档和本地配置不进入网站产物。

不要提交密钥、令牌、账号密码、本机绝对路径或其他私人信息。公开站点验证文件是验证机制要求发布的内容。新增公开文件前检查内容，使用精确文件名暂存，避免意外包含本地文件。
